Позиція плейхеда = (сума ваг попередніх сегментів + вага поточного × частка) / 6.7. Частка: crawling — done/total з progress; brandkit / scripting / directing — done/total з progress × 0.92 (або 0.5, якщо невідомо); awaiting_* — 1 (на ромбі); rendering — (індекс формату + done/total) / кількість форматів; delivered — 100%; revising і failed — плейхед лишається на останній позиції. Чип показує машинний час (сума busy-інтервалів зі state-подій).
