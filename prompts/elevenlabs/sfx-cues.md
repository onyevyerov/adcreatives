Тексти для `textToSoundEffects.convert` (promptInfluence 0.6, eleven_text_to_sound_v2): бібліотека
звуків подій ролика. Зведення (`packages/audio/src/mixer.ts`) бере звук кожної події зі `sound` звідси:
по колу перебирає варіанти cue, обрізає тишу на початку, ставить на кадр події за `anchor`
(riser закінчується на кадрі, whoosh/swoosh/swipe мають пік на кадрі, решта починається з кадру),
а тональні cue (`pitch` tuned/stepped, `PITCHED_SOUND_CUES`: pop, ding, shimmer, notify, success)
підтягує до тональності треку. Поведінка кожного cue — таблиця `SOUND_CUE_TRAITS`
(`packages/shared/src/soundCues.ts`). Варіант 1 стандартних cue хост грає ще й для старого `audio.json`
без `mix` (або коли зведення не вдалося).

Генеруються раз на деплой `pnpm sfx-cache` у `DATA_DIR/cache/sfx/<hash>.mp3` (або `.wav` для
`pcm_44100`); хеш — від тексту, тривалості й формату (`ELEVENLABS_SFX_FORMAT`; `mp3_44100_128` у хеш
не входить), тож зміна рядка тут = новий файл у кеші. Формат рядка (розбирає код):
`- <cue>.<варіант> (<секунди> s): <англійський текст>`; без `.<варіант>` — варіант 1.
Тривалість 0.5–30 с (мінімум API — 0.5). Кожен текст вимагає: звук починається одразу, без тиші
на початку («starts immediately with no silence at the beginning»); сухий («dry»), без довгого
хвоста реверберації; одиночний (один удар, одна нота, одна коротка серія для typing/cheer); гучний
і чистий, по центру стерео («loud and clean, normalized, centered in the stereo image»), а для cue
зі `stereo: "wide"` — широкий, але не в протифазі («wide but not phase-inverted»; старі whoosh/swoosh/riser `.1–.3` лишаються
з «centered…», щоб не перегенеровувати кеш). Тональні cue —
одна чітка нота або чітка перша нота ≥ 150 мс (вікно оцінки висоти), без шуму (тон оцінюється й
підтягується до тональності). Варіанти одного cue помітно різні, але в одному сучасному стилі.

Кожен згенерований семпл проходить QC (`packages/audio/src/sfxQc.ts`): пік ≥ `SFX_QC_MIN_PEAK_DB`,
onset ≤ `maxOnsetMs` cue, кореляція L/R за `stereo` cue (`SFX_QC_MIN_CORRELATION`, для wide —
`SFX_QC_MIN_CORRELATION_WIDE`), для тональних — впевнена висота тону; не пройшов — до 2 повторних
генерацій, у кеш — найкраща спроба.
`pnpm sfx-cache --recheck` — QC наявного кешу безкоштовно; `LIVE=1 pnpm sfx-cache --regenerate-failed`
— перегенерувати ті, що не проходять (платно).
Зведення не бере в ротацію варіант, що не пройшов QC, якщо в cue є інший (пройшов QC або без QC);
якщо не пройшов жоден — грає всі, щоб подія не лишилась без звуку.
